# Project Management Skill

## Use when

- Scoping work, refining requirements, planning milestones, prioritizing, or coordinating handover.

## Checklist

- Read URD, session state, decisions, and open questions.
- Define objective, scope, non-goals, dependencies, owner, and acceptance criteria.
- Separate facts, assumptions, proposals, and unresolved questions.
- Break work into verifiable tasks with clear sequencing.
- Surface legal, security, external-service, and delivery risks.
- Do not promise dates or scope without evidence and ownership.

## Expected output

```text
Objective:
Scope / Non-goals:
Known decisions:
Open questions:
Plan and acceptance criteria:
Risks / Dependencies:
```

## Memory updates

- Always: `memory/SESSION_STATE.md`, `memory/CHANGELOG_AI.md`.
- When applicable: `memory/DECISIONS.md`, `memory/OPEN_QUESTIONS.md`.

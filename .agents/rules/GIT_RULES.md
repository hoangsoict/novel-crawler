# Git Rules

- Inspect status and diff before changes and before handover.
- Treat existing uncommitted changes as user-owned; do not discard or overwrite them.
- Do not initialize a repository, create/switch branches, commit, push, tag, or open a PR unless requested.
- Never rewrite shared history or use destructive reset/clean commands without explicit approval.
- Keep commits focused when commits are requested.
- Do not commit secrets, generated credentials, local configuration, large crawl output, or copyrighted datasets.
- Record changed files and validation in `memory/CHANGELOG_AI.md`.
